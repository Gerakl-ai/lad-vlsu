# Участие в Лад ВлГУ

Спасибо за помощь. Проект независимый и пока не является официальным расписанием университета. Открытый исходный код доступен для чтения; условия повторного использования будут определены после выбора лицензии правообладателем.

## Ошибка расписания

Перед сообщением проверьте [покрытие опубликованных групп](https://gerakl-ai.github.io/lad-vlsu/data/coverage.json). Каталог включает группы, для которых ещё нет снимка; отсутствие данных такой группы не означает, что пар в этот день нет.

В [GitHub Issues](https://github.com/Gerakl-ai/lad-vlsu/issues) укажите:

- группу, институт, дату и числитель/знаменатель;
- какая пара, время, преподаватель или аудитория показаны и что должно быть по первоисточнику;
- адрес публикации и время обновления снимка, если оно отображается;
- ссылку на публичный первоисточник или фрагмент изображения расписания, если есть право его публиковать.

Не прикладывайте личные заметки, экспорт IndexedDB, файлы резервной копии, номера телефонов и другие персональные данные. Для сведений из непубличного документа достаточно описания расхождения; договоримся о безопасной сверке отдельно.

Если источник вернул пустой HTTP 200, укажите это как сбой загрузки, а не как «свободный день». Перед исправлением данных нужна проверка исходной группы и периода действия документа.

## Изменения кода

1. Откройте issue для крупного изменения интерфейса или схемы данных.
2. Делайте небольшие pull request с пояснением сценария и проверок.
3. Запустите `pnpm install`, `pnpm check` и `node --check public/sw.js`.
4. Для изменений PWA проверьте обновление установленной версии и offline reload; для интерфейса приложите мобильный скриншот и проверьте `prefers-reduced-motion`.
5. Не коммитьте личные записи, токены, `.env`, пользовательские PDF или непроверенное расписание в `main`/`data`.

Обновление снимка расписания должно проходить валидацию, включать происхождение, период действия и время проверки. Недостаточная уверенность в строке PDF — повод оставить её в staging и запросить ручную сверку, а не опубликовать догадку.
