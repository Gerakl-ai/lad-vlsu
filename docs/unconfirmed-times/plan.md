# План

- Готово локально: явный контракт DTO/кэша/quality/SW, расчёт времени без фиктивного end.
- Готово локально: Today/Week/календарь/заметки, исключение из уведомлений и безопасный ICS с количеством пропущенных событий. Контекст записки сохраняет неизвестное время; явный личный срок остаётся независимым.
- Готово локально: регрессии, typecheck, build, браузер на четырёх viewport в двух темах, перезапуск с заблокированной сетью данных, сохранение связанной записки, просмотр скриншотов. SW проверен через VM/CacheStorage harness. Этот браузерный fixture не доказывает установку SW на физическом iPhone.
- Готово локально 15.10: строгая расшифровка всех 106 интервалов ИЭиТ. Временные
  расхождения связаны с исходной строкой и соседней конфликтной ячейкой;
  четыре неопределённых end отсутствуют. Подтверждены общий пакет, выбор девяти
  ранее не открытых групп через saved-bundle fixture и data-cache harness.
- Далее: полноценная установка и offline reload на физическом iPhone.
- Публикация отдельно, после согласия Германа.
