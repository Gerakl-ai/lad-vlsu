# Требования и решение

- Подтверждённый DatedLesson сохраняет обязательное окончание позже начала.
- Неподтверждённый DatedLesson имеет дату, напечатанное начало и явный
  `timeStatus: unconfirmed`. Поле end отсутствует. Без флага отсутствие
  окончания остаётся ошибкой, неизвестные значения флага отклоняются.
- LessonSlot хранит это состояние без фиктивного 90-минутного окончания.
  Существующие недельные расписания и ExamSession не меняются.
- HTTP, локальный кэш, общий пакет, quality и SW одинаково проверяют формат.
- Такой предмет виден на Today, Week и в календаре приложения, доступен
  для заметки. Подпись «Время уточняется» не содержит технических терминов.
- Нет расчёта процентов, окончания, перерыва после него, пройденного статуса
  или напоминания с недостоверным временем. Главный блок не заявляет, что
  все пары прошли, пока в этом дне есть неподтверждённое занятие.
- ICS экспортирует только подтверждённые события. Результат команды явно
  сообщает число событий, требующих уточнения. Данные не исчезают из приложения.
- Флаг не исправляет исходник. До импорта нужны проверенные метаданные,
  полный массив предметов, исходные часы и причина каждого конфликта.

Пропуск предмета и фиктивное окончание отвергнуты: оба искажают расписание.
Отдельный непрокручиваемый технический баннер не нужен: состояние относится
к конкретному предмету, остаётся рядом с ним и работает офлайн.

Проверки: валидаторы всех слоёв, время до/после начала и даты, старый кэш,
прогресс, календарь/ICS, оба типа расписания, заметки, 402/430/874/1440,
длинные названия, обе темы, offline reload и сохранение выбора пары.
