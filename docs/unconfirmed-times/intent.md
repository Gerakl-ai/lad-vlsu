# Неподтверждённые часы занятий

Сохранить все напечатанные предметы группы при противоречивых часах источника.
Не придумывать окончание, не пропускать предметы и не показывать неподтверждённую
пару как текущую или пройденную. Модель нужна для общего расписания ВлГУ,
не только для двух январских ячеек ИЭиТ.
