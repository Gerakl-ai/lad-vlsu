## Проверка импорта

`scripts/spreadsheet/stage_dated.py` читает XLSX, не изменяя его. Группа
определяется по точному заголовку, год по объявленному учебному году, дата и
время по объединениям исходных ячеек. День недели сверяется с датой. Часы,
напечатанные внутри предметной ячейки, имеют приоритет над общей колонкой.
При неоднозначной дате, аудитории, преподавателе или отсутствии часов импорт
останавливается. Отсутствующий тип занятия сохраняется пустым. Отдельные
интервалы из общей колонки не склеиваются через напечатанный перерыв.

В staging каждой записи оставлены исходный текст и адреса предмета, группы,
даты и часов. Проверены все извлечённые ячейки и геометрия объединений;
контрольные области дополнительно просмотрены на изображениях таблиц.
Это не подтверждение актуальности осеннего расписания и не независимая
повторная редакторская сверка каждого сокращения в исходном документе.
Сокращения и опечатки источника не раскрываются предположениями.

Одобрение зафиксировано в `scripts/spreadsheet/reviewed-spring-2026.json`:
точный Nrec, лист, период, число записей, хэш файла и полный хэш извлечённых
занятий с доказательствами. `buildReviewedDatedSnapshot.mjs` отклоняет
изменившийся staging. Готовые снимки лежат в `public/data/reviewed-schedule/`.

Пример воспроизведения после загрузки неизменившегося официального файла:

```text
python -m pip install -r scripts/spreadsheet/requirements.txt
python scripts/spreadsheet/stage_dated.py --source artifacts/source-discovery/spring-2025-26/gumi_ozo.xlsx --sheet "ВПЛ-124,ВПЛм-124" --group "ВПЛм-124" --source-url https://www.vlsu.ru/fileadmin/class-schedule/2025-2026/vesna/gumi_ozo.xlsx --out artifacts/source-discovery/spring-2025-26/vplm-124.stage.json
node scripts/spreadsheet/buildReviewedDatedSnapshot.mjs --stage artifacts/source-discovery/spring-2025-26/vplm-124.stage.json --catalog public/data/catalog.json --review scripts/spreadsheet/reviewed-spring-2026.json --out public/data/reviewed-schedule
```

## Поведение приложения

- Формат `DatedLesson` содержит ISO-дату, отдельные `start`/`end` и обычный текст
  предмета. Он нормализуется в `scheduleKind: classes`, не в экзамен.
- «Неделя» показывает список дат, аудитории, преподавателей, архивный период и
  прямой переход к выбранному дню. Записка и ДЗ привязываются обычным способом.
- На нынешнюю дату за пределами периода не показываются ложные свободные дни.
  Кнопка открывает последний день сохранённых занятий.
- GitHub Pages включает снимки в единый пакет, покрытие, качество и отдельные
  файлы расписаний. Service worker принимает и сохраняет датированный формат.
- Сравнение данных отдаёт приоритет действующему семестру перед просроченным
  архивом, даже если архив импортирован позже.
- Студенту не предлагается отдельный Excel-интерфейс. Происхождение остаётся
  в данных и документации сопровождения.

На наборе ветки `data` от 12.10, 11:02 UTC сборка с этими архивами дала
655/963 группы и 308 пробелов. Это покрытие с учётом старых таблиц, не 655
подтверждённых расписаний текущего семестра. Учебные периоды 59 групп
по-прежнему считаются отдельно.
