# Диагностика PDF ИЭиТ

Проверка 14.10.2026. Источник:
[DO_IEHIT_190126-240126.pdf](https://www.vlsu.ru/fileadmin/class-schedule/2025-2026/osen/exam/DO_IEHIT_190126-240126.pdf).
Файл повторно скачан, SHA-256 прежний:
`f3a227e0f26fa2ea6542eb5eaede60f5d55ab9a67cf138ab37df20e31d1ddb5a`.
Период в общей шапке: 19-24.01.2026. Это архив, не текущий семестр.

## Невидимый слой

В PDF один лист, девять колонок групп, общая строка периода и 30 строк таблицы.
3917 белых символов в текстовом слое не видны на отрендеренной странице.
Среди них M-маркеры размера 0,1 pt и более крупные числовые идентификаторы
в пустых предметных клетках. Только фильтр мелкого шрифта проблему не решает.
Удаление чисел по регулярному выражению может удалить настоящую аудиторию.

В `scripts/pdf/inspect_dated_pdf.py` добавлена диагностическая выгрузка:

- Белый текст исключается только по явному `--white-body-background` после
  визуальной проверки белого фона предметных ячеек. По умолчанию ничего не удаляется.
- Геометрия таблицы остаётся исходной. Поворот часов и даты читаются PDFium,
  цветные видимые предметные строки читаются с сохранёнными координатами.
- Каждая строка хранит видимый текст, полный исходный текст с маркерами,
  границы предмета, часов и даты, напечатанные часы сетки и отдельное начало
  внутри ячейки. Шрифт и цвет не используются для угадывания вида занятия.
- Формат `inspection-only` builder отвергает даже с подписанным массивом.
  Выгрузка не находится в public и не прибавляется к покрытию.

## Конфликты источника

Из девяти отличий семь начинаются в 16:00 внутри сетки 15:50-17:20.
Их начало нужно сохранить по предметной ячейке, не сдвинуть на 15:50.

Два отличия противоречат даже границам строки:

- ЗГМУмд-125, 21.01: «Теория и механизмы современного государственного
  управления» напечатана с 16:00 в строке 12:10-13:40. В тот же день другая
  дисциплина также начинается в 16:00. Окончание и взаимное расположение
  по источнику однозначно не определены.
- ЗМНмупд-125, 20.01: «Деловой иностранный язык» начинается в 16:00,
  но помещён в строку 17:40-19:10. Другая пара этой группы в этот день
  тоже начинается в 16:00. Не назначать окончание 19:10 по положению клетки.

У физкультуры не всегда напечатан вид аттестации. У переаттестаций фамилия
стоит в скобках после предмета; пометки п/а сохраняются отдельно. Общие
собрания относятся только к объединённым колонкам, не ко всем девяти группам.

Нельзя молча пропустить конфликтные предметы или придумать окончание.
Следующий этап: строгая расшифровка остальных метаданных, сохранение явного
начала и отдельное представление неподтверждённого времени, либо другой
официальный источник для двух конфликтных дат. До этого снимки не утверждены.

## Воспроизведение

```text
python scripts/pdf/inspect_dated_pdf.py --source <official.pdf> --source-url <official-url> --groups ЗБИмд-125 ЗГДуд-125 ЗГМУмд-125 ЗМНмупд-125 ЗТРуд-125 ЗУКд-125 ЗЭБд-125 ЗЭБуд-125 ЗЭКмд-125 --white-body-background --out <inspection.json>
python -m unittest discover -s scripts/pdf -p test_*.py
```

На этом ПК для старых OCR-тестов отсутствовал PyMuPDF. Версия 1.28.2
установлена только в игнорируемый `artifacts/python-pdf`, без изменения общего
Python. При запуске всей PDF-матрицы этот каталог добавлен в PYTHONPATH.
Все 47 Python-тестов прошли. Контракт builder отдельно проверяет отказ
импортировать inspection-only; основной набор Vitest теперь содержит 509 тестов.

Доказательства локально: `artifacts/source-discovery/spring-2025-26/dot-2025-26/ieit-inspection.json`
и четыре `ieit-*-top/bottom.png`. Исходный PDF не изменён.
