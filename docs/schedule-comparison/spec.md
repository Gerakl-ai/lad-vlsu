# Требования

- Вход из вкладки «Неделя», отдельная кнопка «Сравнить группы».
- Основная группа слева, выбранная дополнительная справа. Последняя дополнительная группа сохраняется отдельно.
- Один день для обоих расписаний: дата, предыдущий/следующий день, возврат на сегодня. Для обычных занятий тип недели вычисляется по академическому календарю ВлГУ, как на экране Today. Старый API/snapshot не переворачивает неделю, ручной переключатель другого экрана не влияет. Сессия остаётся привязана к конкретным датам.
- На телефоне два списка рядом с переносами полного названия, аудиториями, преподавателями и временем начала/конца. Не заставлять горизонтально прокручивать страницу.
- Сначала локальный кэш, затем существующая загрузка статических/серверных данных. Не переписывать выбор основной группы.
- Общие свободные интервалы только внутри явно выбранного диапазона 08:00-20:00. Пересечения считаются по времени, соседние интервалы объединяются; минимум окна 20 минут.
- При отсутствии данных на дату, данных второй группы или наличии неизвестного конца занятия точные окна не выдаются. Предварительное/устаревшее расписание явно помечается.
- Личные события и заметки не участвуют в сравнении групп и не передаются другим людям.
- Закрытие, Escape, фокус, темы и малый landscape проверяются. Нет постоянных анимационных циклов.
