# Импорт датированных расписаний

ЛАД должен открывать расписания всех групп ВлГУ, включая группы с пустым ответом
API. Найденные официальные таблицы заочных сессий дают предметы, даты и часы,
которых нет в доступном API. Они пригодны для архивного просмотра, но не
подтверждают занятия текущего семестра.

Сохраняем исходную цель всего проекта из `../VLSU-PRODUCT-ROADMAP.md`.
Этот этап добавляет достоверные архивы и повторяемый способ сверки документов.
Записи пользователей, текущие источники и прежние расписания не заменяем.

Первый документ: две группы ИИТЭ, ЗИСТуд-124 и ЗИСТуд-224, 1-6 декабря 2025.
Остальные найденные документы проверяем отдельно, без переноса правил по догадке.
