# Требования

- Источник: официальный HTTPS URL ВлГУ, SHA-256 файла, точный заголовок группы.
- Геометрия ячейки берётся из таблицы PDF, текст из PDFium. Поворот текста часов
  не должен превращать время начала в время конца.
- У каждой строки сохраняются дата, начало, конец, исходный текст и координаты
  предмета, часов, дня и заголовка группы.
- День недели сверяется с календарной датой и напечатанным периодом группы.
- Каждая непустая предметная ячейка должна иметь напечатанный интервал.
  Отсутствие часов, неизвестные метаданные или конфликт периода блокируют импорт.
- Объединение ячейки не поглощает напечатанные перерывы. Общая ячейка нескольких
  групп относится ко всем указанным группам. Языковые варианты сохраняются.
- Занятия и аттестации имеют тип DatedLesson с явным scheduleKind. Старые XLSX
  без этого поля продолжают считаться обычными занятиями.
- Публикуемый снимок собирается только после сверки и подписания массива строк.
  Исходные PDF не меняются. В интерфейсе обычные занятия, без технических терминов.
- Архив не повторяется по неделям и не описывает текущий день как свободный.
- Общий пакет содержит новый архив для офлайн-выбора ранее не открытой группы.

Проверки: Python, Vitest, TypeScript, production build, синтаксис SW, браузер
402x874, 430x932, 874x402 и 1440x900, офлайн-выбор и reload. Реальный iPhone
проверяется отдельно и не считается проверенным по эмуляции.
