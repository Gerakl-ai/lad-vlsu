## Неполные метаданные

Две ячейки ЗХТуд-125 сверены отдельно. Расшифровки находятся в
`scripts/pdf/reviewed-dated-ibie-metadata.json`. Они привязаны к хэшу источника,
группе, дате, началу, концу, странице, точным границам и исходному тексту.
Изменение источника, отсутствие или несовпадение ячейки блокирует обработку.
Снимок дополнительно подписан полным хэшем строк с доказательствами.

- 21.01, 15:50-17:20: физкультура и переаттестация электротехники.
  Аудитория 101-СК1 и Стародубцева С.В. указаны только у физкультуры.
  У электротехники поля оставлены пустыми, варианты сохранены отдельно.
- 23.01, 12:10-13:40: иностранный язык, переаттестация и зачёт, 303 а-1.
  Шаломова Е.В. напечатана только у зачёта, у переаттестации её не назначаем.
- «Денисов Ил.В.» и «п/а» сохранены как напечатано. Инициалы не исправлены
  на более привычные по догадке. Пометка не включается в название предмета.
- Перенесённые аудитории 315 а-3, 427 а-2, 326 а-1 читаются целиком.

Остальные неполные строки reader по-прежнему отклоняет. Девять ранее
проверенных архивов ИИТЭ извлечены повторно с прежними хэшами всех строк.

## Совместимость календаря

Длинные строки ICS теперь переносятся по 75 байтам UTF-8, без разрыва
символа. Добавлены завершающий CRLF и экранирование Windows-переносов
в заметках. Основание: [RFC 5545, раздел 3.1](https://www.rfc-editor.org/rfc/rfc5545#section-3.1).
После обратного объединения строки UID прежние, новые дубликаты из-за
переноса не создаются. Выбранные название, аудитория и преподаватель
проверяются по отдельным свойствам, не по исходному непрозрачному UID.

В браузерном QA нативный Web Share выключен для проверки скачивания.
Физический iPhone, Share Sheet и нативный импорт календаря не проверены.
Изменения локальные; публикация требует подтверждения Германа.

```text
node scripts/spreadsheet/buildReviewedDatedSnapshot.mjs --stage <stage.json> --catalog public/data/catalog.json --review scripts/pdf/reviewed-dated-ibie-january-2026.json --out public/data/reviewed-schedule
pnpm run check

node --check public/sw.js
```
