# Лад ВлГУ: подготовка университетской версии

Дата: 01.10.2026. Пилот опубликован на GitHub Pages; Cloudflare Worker проверяется отдельно.

## Название и первая встреча

Название продукта: «Лад ВлГУ». Новое имя репозитория согласовано: `lad-vlsu`.
Приложение остаётся независимым студенческим проектом до согласования с университетом.
Название ВлГУ само по себе не означает официального статуса.

Первый запуск показывает выбор группы, без автоматической установки ПИ-124.
Группу можно найти сразу по названию среди всех институтов. Поиск принимает `пи124`,
`ПИ 124` и `ПИ-124`. Можно также пройти через институт. После выбора пользователь
видит обычные экраны расписания. Выбор запоминается, личные записи сохраняются отдельно.
Прямые ссылки на группы сохраняются для студентов, преподавателей и избранных групп.

## Покрытие, которое можно показывать

- Каталог: 966 групп на 01.10.2026.
- Подготовлено 649 непустых снимков: 632 доступны из API, 17 дополнены резервными данными.
- Распознанные данные имеют исходный документ, хэш и координаты для внутренней проверки.
- Для остальных 317 групп текущий источник пока не найден. Их нельзя выдавать за покрытые.
- Покрытие каталога не равно гарантии правильности каждой пары. Проверка распознавания продолжается.
- Пользователь получает обычные карточки занятий, источник импорта остаётся внутри системы.
- Студент видит дату обновления и состояние офлайн-доступа; подробные метаданные опубликованы в репозитории.

## Репозиторий и действующие установки

Прежний репозиторий: `Gerakl-ai/vlsu-pi-124-schedule`.
Прежняя адресная схема Pages: `/vlsu-pi-124-schedule/`.
Сохранение этого пути необходимо для открытия старых установок и экспорта записей.
Внешнее имя репозитория можно изменить, но для установленной PWA адрес является
частью идентичности: manifest id, start_url, scope и область service worker.
Заметки IndexedDB привязаны к origin. Смена домена создаёт отдельное хранилище.
Даже при сохранении домена новый путь меняет scope и может создать вторую установку.

GitHub перенаправляет репозиторий после переименования, но исключает URL проектного
сайта из гарантии перенаправления:
https://docs.github.com/en/repositories/creating-and-managing-repositories/renaming-a-repository

Основной репозиторий переименован в `Gerakl-ai/lad-vlsu`.
Прежний адрес сохранён отдельным репозиторием `Gerakl-ai/vlsu-pi-124-schedule`
с чистым снимком прежнего кода и веткой данных. Оба Pages URL открываются;
CI и публикация прошли. GitHub заблокировал перенос старой истории из-за
потенциального секрета в историческом коммите. Старый репозиторий не содержит
эту историю. Секрет в основной истории нужно проверить и при необходимости
отозвать.

Для перехода действующих установок остаются проверки:

1. Зафиксировать адреса всех действующих установок, manifest id/scope, cache scopes и origin записей.
2. Проверить экспорт и импорт записей, вложений и личных событий, не удаляя старую установку.
3. Выбрать стабильный адрес продукта с владельцем и ответственным за инфраструктуру.
4. Сохранить обслуживание старого пути и его worker. Переход выполняется добровольно.
5. Проверить старую и новую установку онлайн, офлайн и при обновлении в Safari iOS.

## Очерёдность следующей разработки

1. Данные: инвентарь по институтам и формам обучения, проверка паритетов и подгрупп,
   сверка сложных ячеек, поиск источников для 317 оставшихся групп.
2. Надёжность: первый запуск без сети, загрузка другой группы при недоступном API,
   восстановление старых установок и сохранность записей на реальном iPhone.
3. Понятность: показывать ближайшую пару и день без лишних индикаторов; закрепить
   явные действия «Сменить группу», «Календарь», «Добавить запись» и «Обновить».
4. Пилот: несколько групп из разных институтов и форм обучения, студенты и преподаватели,
   фиксированный список задач и регистрация расхождений с официальным расписанием.
5. Университет: согласование выгрузки, обновления, ответственного за данные и обратной связи.
6. Публикация: лицензия, инструкция запуска и обновления, доступность, перечень ограничений,
   сохранение старого адреса и проверенный релиз для демонстрации.

## Критерий готовности к общей рекомендации

Ни один институт не имеет скрыто отсутствующих расписаний. Каждый опубликованный
снимок подтверждён источником и сроком действия. Изменения числителя/знаменателя
проверены на реальных занятиях. Первый запуск, повторный запуск без сети, выбор
другой группы и сохранность записей проходят проверку на iPhone и Android.
Директору можно показать текущий пилот, но заявлять готовое массовое внедрение
следует после выполнения этих условий.
