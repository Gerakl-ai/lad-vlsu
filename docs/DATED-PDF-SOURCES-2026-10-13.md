## Сверенные колонки ИИТЭ

- ЗИСТуд-124: 28 напечатанных интервалов, 16 занятий и 12 аттестаций,
  27 предметных ячеек. ЗИСТуд-224: 28 интервалов, 16 занятий и 12 аттестаций,
  28 предметных ячеек. Две общие языковые ячейки дают 53 уникальные ячейки.
- Все строки сопоставлены агентом с отрендеренной страницей PDF. Это не
  независимая сверка владельцем расписания и не подтверждение актуальности.
- 3 декабря в 14:00 сохранены три языковых варианта, в 15:50 два. Преподаватели
  и аудитории каждого варианта остаются отдельными.
- Экзамен «Управление данными» 6 декабря у ЗИСТуд-124 занимает два напечатанных
  интервала 14:00-15:30 и 15:50-17:20. В 15:40 пары нет.
- Адреса `404 а-2`, `216 б-2`, `205 в-3` сохраняются целиком.
- Даты относятся к декабрю 2025. Архив не повторяется в последующие недели,
  не подменяет действующее расписание и не создаёт ложного свободного дня.

Сверка зафиксирована в `scripts/pdf/reviewed-dated-iite-2025.json`.
Каждая публичная запись имеет координаты PDF и исходный текст в sourceCells.
Строгий builder проверяет подписанный массив строк, группу, форму обучения,
период и геометрические доказательства. Неизвестный тип занятия блокирует импорт.

- `переат` и `+п/а` сохраняются как пометки источника. Значение `+п/а` не

  полный период 26-31.01.2026, исходный файл и подпись каждой колонки.

При браузерной проверке выявлено расхождение календаря и выбранной аудитории.
Теперь календарь и месячный экспорт ICS используют тот же resolver выбора,
что Today и Week. Календарная дата определяет тип недели, исходные данные
не мутируют. Скачанный ICS проверен по UTC-границам и выбранному LOCATION.
В QA выключен нативный Web Share, чтобы тест не открывал системный диалог.
Настоящий Share Sheet и импорт на физическом iPhone не проверены.

## Воспроизведение

```text
python -m pip install -r scripts/pdf/dated-requirements.txt
python scripts/pdf/stage_dated_pdf.py --source <официальный PDF> --group ЗИСТуд-124 --source-url https://www.vlsu.ru/fileadmin/class-schedule/2025-2026/osen/exam/DO_IITEH_ZISTud.pdf --out <staging.json>
node scripts/spreadsheet/buildReviewedDatedSnapshot.mjs --stage <staging.json> --catalog public/data/catalog.json --review scripts/pdf/reviewed-dated-iite-2025.json --out <результат>
python -m unittest discover -s scripts/pdf -p test_stage_dated_pdf.py -v
```

Локальные исходники и черновики находятся в игнорируемой папке
`artifacts/source-discovery/spring-2025-26/dot-2025-26`. Reader использует
pdfplumber для границ и PDFium для текста повёрнутых часов. Ячейки без
полного разбора остаются ошибками; staging не публикуется сам.

Проверки после январского этапа: 493 Vitest-теста, 11 Python-тестов reader, TypeScript,
build, SW syntax и Cloudflare dry-run. Браузерные сценарии двух групп:
402x874, 430x932, 874x402, 1440x900; календарь, окно записки, offline UI choice
и reload. Выбор языка согласован в Today/Week и сохраняется после reload;
375x812, 874x402 и 1440x900 в светлой и тёмной темах проверены. Семь новых групп
выбраны через поиск и перезапущены без сети. Личный календарь также проверен:
создание, редактирование, удаление события, свайп месяца и сохранение после reload.
Его старый QA обновлён на валидный ID группы вместо непригодного пустого снимка.
Физический iPhone не проверен.

На входных данных `origin/data` dd028781 и fallback main общий пакет даёт
664/963, 299 пробелов, 0 отклонённых снимков. В main каталог старше:
664/966, 302 пробела. Опубликованный релиз остаётся 768e777 с 655 расписаниями.
Новый результат пока локальный, публикация ждёт подтверждения.
