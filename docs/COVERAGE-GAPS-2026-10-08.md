# Пробелы покрытия расписанием на 08.10.2026

## Проверенное состояние

Последний опубликованный обход ветки `data` стартовал 08.10.2026 в 10:35 UTC. В каталоге было 963 группы. Официальный API вернул 632 непустых расписания и 331 пустой ответ. С учётом сохранённых снимков пакет содержит 649 расписаний, без снимка остались 314 групп.

Формы обучения среди 314 групп без снимка: 256 заочных, 43 очных, 15 очно-заочных. Ни одна из них не найдена в текущем `document-index.json`, который связывает группы с тремя опубликованными приказами об осеннем расписании. Это не значит, что расписаний нигде нет. Это значит, что у проекта пока нет проверенного источника для этих групп.

Проверка на официальном [сайте расписания ВлГУ](https://student.vlsu.ru/schedule/institute): заочная ЗМТИ-122 запрашивается через тот же `student/GetGroupSchedule` с `WeekType: 0` и `WeekDays: 1,2,3,4,5,6`; сайт показывает «Расписание не найдено». На [странице приказов](https://www.vlsu.ru/studentu/raspisanie-zanjatii) сейчас опубликованы документы для очной, очно-заочной формы и колледжа, но не новый общий приказ для заочной формы.

## Как воспроизвести подсчёт

```text
node scripts/snapshot/coverageGapAnalysis.mjs
node scripts/snapshot/coverageGapAnalysis.mjs path/to/catalog.json path/to/coverage.json path/to/document-index.json
```

Без аргументов скрипт считает локальный пакет `public/data`. Для текущей публикации нужно передать файлы ветки `data`; её каталог может отличаться от локального. Локальный пакет от 05.10 содержит 966 групп, 649 снимков и 317 пробелов.

## Следующие источники

1. Для 43 очных групп без снимка проверить актуальность группы в каталоге и наличие расписания на кафедральных страницах. Публиковать только данные с датой действия и проверяемым происхождением.
2. Для 15 очно-заочных групп проверить обновления приказа и индивидуальные документы институтов.
3. Для 256 заочных групп учитывать, что расписание может публиковаться под конкретную сессию, а не на всю неделю семестра. Нужен датированный источник; пустой ответ API не означает свободный день.
4. Обсудить с ИТ-службой ВлГУ доступ к достоверной выгрузке и правила нагрузки на API. Штатный обход уже опрашивает каталог раз в три часа; дополнительный массовый обход вручную не нужен.

Пока источника нет, приложение должно показывать отсутствие данных и ссылку на официальный сайт. Заполнять пробелы похожими парами соседних групп нельзя.
