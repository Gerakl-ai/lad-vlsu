# Контракт восстановления

- Обход записывает instituteId, форму обучения и ошибку конкретного запроса.
- Восстановление применяется только к schemaVersion 3 и отчёту того же обхода: status.startedAt должен совпадать с catalog.capturedAt.
- Для провалившихся запросов берутся группы предыдущего каталога, затем проверенного каталога из main. Успешные формы обучения, новые названия и текущий курс не подменяются старыми.
- Нельзя восстанавливать удалённый институт, переносить nrec между институтами или выдавать невалидный профиль за существующую группу.
- Сохранённые формы и дата их исходного каталога помечены в данных. Повторный сбой не обновляет эту исходную дату.
- Полный успешный ответ не объединяется безусловно со старым каталогом: подтверждённые удаления сохраняются.
- Общий compiler использует ту же политику, чтобы защитить публикацию уже повреждённой ветки data. Pages и snapshot workflow передают --catalog-fallback явно.
- Учебные периоды не считаются таблицей пар. Сохранённый профиль без расписания остаётся пробелом покрытия.
